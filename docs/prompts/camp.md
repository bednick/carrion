# Промпт: Лагерь (CampScene)

## Технические параметры

| Параметр    | Значение                                          |
|-------------|---------------------------------------------------|
| Сцена       | CampScene — статичный полноэкранный фон           |
| Размер      | 1920×800 (было 1280×800, см. «Расширение по бокам») |
| Соотношение | 2.4:1                                             |
| Слоёв       | 1 (статика)                                       |

## Описание сцены

Лагерь игрока у края поля после крупного сражения. Ночь или поздние сумерки.
Персонажи (кузнец, скупщик, герой у костра) — **не включать**, они добавляются движком поверх.
Фон должен читаться как место: земля, дальний план, небо.

Левая треть — место кузнеца (темновато, кирпичная кладка или деревянный навес).
Центр — место костра (слегка освещено тёплым огнём снизу, земля вытоптана).
Правая треть — место скупщика (навес или повозка, фонарь или факел).

## Расширение по бокам (outpaint под широкие экраны)

Высота холста фиксирована (800), ширина зависит от аспекта монитора и доходит до 1920 (`src/ui/layout.ts`). Старый
`camp.png` (1376×768) не имеет запаса по бокам, поэтому его тянет по ширине. Нужен файл **1920×800**, у которого
**центральные 1280×800 — это в точности текущая композиция** (кузнец слева, костёр в центре, повозка скупщика справа,
сундук). Тогда `CampScene` рисует его 1:1: центр остаётся попиксельно тем же, а по бокам просто открывается больше
сцены. Позиции НПС пересогласовывать не придётся.

Режим Nano Banana — **редактирование с референсом**: приложить текущий `public/backgrounds/camp.png`.

```
Используя приложенное изображение как точный эталон, расширь эту же сцену влево и вправо до соотношения 2.4:1
(итог 1920×800). Существующая композиция должна остаться в центре кадра без изменений — не перерисовывай, не сдвигай
и не перекрашивай ничего внутри неё: кузница слева, вытоптанное кострище в центре, повозка скупщика справа, земля,
дальний план и небо должны совпасть по линии стыка пиксель в пиксель. Дорисуй только новые полосы примерно по 320
пикселей с каждого края, продолжая ту же сцену: покосившийся частокол, брошенные телеги, свёрнутые палатки, ящики и
бочки, обломки щитов в грязи, дальше — силуэты мёртвых деревьев и туман над полем битвы. Та же техника пиксель-арта,
та же холодная десатурированная палитра (серый, синий, фиолетовый, тёмно-зелёный), тот же уровень освещённости: тёплый
свет от костра остаётся только в центре, по краям — почти темнота, слабые огни фонарей. Линия горизонта и линия земли
продолжаются на одной высоте, без ступеньки. Без людей, без монстров, без животных, без UI, без текста, без рамок,
без подписей.
```

После генерации — доводка в Aseprite (шов по стыку, чистка палитры), затем файл кладётся на прежнее место
`public/backgrounds/camp.png`, и в `CampScene` константа `CAMP_BG_W` меняется с `GAME_W` на `1920`.

## Цветовые ориентиры

- Небо: тёмно-синий/серый (#1a1a2e — цвет фона игры)
- Земля: тёмно-коричневый, мокрый грунт
- Свет костра: тёплый оранжевый (#cc6600), только в центре
- Факелы/фонари: слабый жёлтый по краям
- Деревья/руины вдали: почти силуэты, тёмно-серый
