# Мёртвые поля ★☆☆

**Фракция:** Магия — Нежить
**Тип:** стартовая
**Открывается:** с начала игры

## Лор

Равнина где стояли войска магической фракции. После битвы земля выжжена, трава поседела. Остатки магических ритуалов удержали павших на ногах.

## Мобы

Зона знакомит с **фракционной защитой Нежити — блоком** (`defense.block`, шанс погасить удар целиком). HP тут
намеренно крошечный: полоса тела ничего не значит, значение имеет число **прошедших** ударов. Отсюда и урок
фракции — тяжёлый редкий замах теряет от одного неудачного ролла целый цикл, частое лёгкое оружие усредняет
потери (см. [`factions.md`](../factions.md)).

### Поднятый пехотинец `common`

Магия подняла тело, но не разум. Медленный, тупой, бьёт один раз. Тир **вводный** — костяк стартовых зон.

**Механика: блок** (`defense.block: 0.6`) — тело ещё в остатках доспеха, больше половины ударов уходит впустую.

- health: 8 / attack_damage: 2 / attack_interval: 1.5s
- Атака: одна полоска, один удар

### Скелет `uncommon`

Без плоти — легче и чуть быстрее пехотинца, но и выдержать удар сложнее. Тир **обычный**.

**Механика: блок** (`defense.block: 0.8`) — бить по голым костям почти бесполезно: удар проходит между рёбер.
Взамен HP символический — доходят единицы ударов, но каждого хватает.

- health: 4 / attack_damage: 2 / attack_interval: 1.25s
- Атака: одна полоска, один удар

### Восставший сержант `uncommon` — босс

Командный состав, поднятый намеренно. Сложнее рядовых.

**Механика: фаза + блок** — при «гибели» (HP до 0) — анимация: голова отлетает, тело продолжает двигаться.
Начинается **фаза 2** — рыцарь без головы, медленнее но сильнее, и блокирует ещё лучше. HP второй фазы
независим, урон через границу смерти не переносится — оверкил крупным ударом пропадает дважды.

**Фаза 1 — Сержант:**
- health: 20 / attack_damage: 2 / attack_interval: 1.25s / `defense.block: 0.5`

**Фаза 2 — Рыцарь без головы:**
- health: 20 / attack_damage: 4 / attack_interval: 1.75s / `defense.block: 0.7`
