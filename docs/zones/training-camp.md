# Тренировочный лагерь (обучающая зона)

**Фракция:** нет | **Тип:** обучающая, вне карты/маршрутов
**Открывается:** с начала игры — единственная доступная активность, пока не пройдена

## Лор

Двор у самого костра, огороженный частоколом. Здесь новичков учат держать оружие прежде, чем отпустить за край
поля, где сошлись три фракции. Не поле битвы — учебные столбы с чучелами и клетка с пленником у забора.

## Статус в системе зон

В отличие от девяти боевых зон, `training-camp` **не входит** в `ALL_ZONE_IDS`/`FACTION_ROUTES` (`src/zones/
registry.ts`) и никогда не появляется в общем списке карты (`MAP_ZONE_LAYOUT`, `CampScene`). Пока она не пройдена
(`MetaStore.tutorial_completed === false`), карта лагеря показывает только её собственную плитку по центру
(`CampScene.buildTrainingCampNode`); ни одна из обычных зон не видна и не доступна. Разблокировка «Мёртвых полей»
и посадка её двух стартовых квестов происходит автоматически сразу после прохождения этой зоны
(`QuestSystem.grantTutorialUnlock`), без участия НПС-квеста. Подробности — `docs/content.zones.format.md`
§«`tutorial`», `docs/meta-progression.md` §«Инициализация».

Зона не даёт лута (`mob_loot`/`boss.loot` пусты) и не показывает стандартный экран драфта награды за босса —
вместо этого сразу после победы над последним мобом игрок возвращается в лагерь, где Информатор вручает **Латы
отчаяния** (`desperate_plate`, common) диалогом (`DialogSystem.checkTutorialRewardDialog`). Это же прохождение
навсегда закрывает саму зону — плитка больше нигде не показывается.

Стартовое оружие героя — кинжал (`dagger`, common), выдаётся по умолчанию каждой новой игре
(`MetaStore.defaultStands`), так что зона проходится именно им.

## Мобы

### Соломенное чучело `straw_dummy` (common) — 3 рядовых боя подряд

Учебная мишень на деревянной палке — не отвечает ударом. `mob_pool` зоны состоит из единственной записи, поэтому
все 3 рядовых боя гарантированно этот моб (детерминированный взвешенный ролл по одной записи).

- health: 5 / attack_damage: 0 / attack_interval: 2.0s
- Атака: одна полоска, урон 0 — движок не создаёт «Блок»/числовой флоатер на нулевом уроне (проверено по
  `src/combat/CombatEngine.ts`/`resolution.ts`), чучело просто «машет», не влияя на HP героя.

### Скованный мертвец `bound_corpse` (common) — финальный бой зоны

Пленная нежить, которую держат на цепи как живую учебную цель — уже слабо огрызается.

- health: 15 / attack_damage: 1 / attack_interval: 2.5s
- Без `defense`/`summons`/`phases`.

> Числа — первая консервативная прикидка (без Monte-Carlo, по конвенции нового контента), не пересчитывались
> балансным симулятором: `npm run balance` эту зону не покрывает (нет лута/влияния на экономику, см.
> `docs/roadmap.balance.md`).
